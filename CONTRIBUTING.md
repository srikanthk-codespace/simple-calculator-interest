# Contributing

Thank you for considering contributing to this project.

## How to Contribute

1. Fork the repository.
2. Clone your fork to your computer.
3. Create a branch for your change:

   ```bash
   git checkout -b feature-your-change
   ```

4. Make your changes and test them.
5. Check your changes:

   ```bash
   git status
   git diff
   ```

6. Commit your work with a clear message:

   ```bash
   git add .
   git commit -m "Describe your change"
   ```

7. Push your branch:

   ```bash
   git push -u origin feature-your-change
   ```

8. Open a pull request describing what you changed and why.

## Contribution Guidelines

- Keep changes focused and easy to review.
- Use clear, descriptive commit messages.
- Update documentation when behavior or usage changes.
- Test scripts before submitting a pull request.
- Be respectful and follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Issues

When opening an issue, include steps to reproduce the problem, expected behavior, actual behavior, and relevant error messages.
