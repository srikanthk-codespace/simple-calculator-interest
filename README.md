# Simple Interest Calculator

A small Bash project that calculates simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal** is the initial amount.
- **Rate** is the annual interest rate in percent.
- **Time** is the duration in years.

## Usage

1. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

2. Run it:

   ```bash
   ./simple-interest.sh
   ```

3. Enter the principal, annual rate, and time when prompted.

The script prints the simple interest and the total amount (principal + interest).

## Example

For a principal of `1000`, rate of `5`, and time of `2` years:

- Simple interest: `100`
- Total amount: `1100`
